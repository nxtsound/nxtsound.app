Support

Help for the NxtSound app and server.

Get in touch

Questions, bugs and ideas go to the issue tracker on GitHub (a free GitHub account is needed):

  • App problems: nxtsound-ios issues
  • Server and web app: nxtsound-server issues

Please do not post passwords or private data. A security problem should not be reported in public: use the Report a vulnerability button on the Security tab of the repository.

Before you start

The app needs a NxtSound server, a free open source program that runs on your own hardware. It has no music of its own. Setup with Docker takes a few minutes: setup guide.

Common questions

The app asks for a server address. Enter the address of your server, for example https://music.example.com or, at home, 192.168.1.5:8000. The app only links to servers that identify as NxtSound.

The server cannot be reached. Check that the server is running and that the address works in the iPhone's browser. For a server in your home network, allow local network access when iOS asks. Songs you saved for offline use stay playable without a connection.

Offline songs. Open the profile menu, then App settings, and switch on the offline section. You choose how many of your last and most played songs are kept and can pick single songs.

Music stops in the background. The app plays with a native player, so it keeps going with the screen locked. If it stops, please report it with your iOS version and what happened.

Remove everything. App settings → Log out and remove server deletes the session and all saved songs on the device.

Support

Hilfe zur NxtSound-App und zum Server.

Kontakt

Fragen, Fehler und Ideen gehören in den Issue-Tracker auf GitHub (ein kostenloses GitHub-Konto ist nötig):

  • Probleme mit der App: nxtsound-ios Issues
  • Server und Web-App: nxtsound-server Issues

Bitte poste keine Passwörter oder privaten Daten. Ein Sicherheitsproblem bitte nicht öffentlich melden, sondern über Report a vulnerability im Reiter Security des Repositorys.

Vorab

Die App braucht einen NxtSound-Server, ein freies, quelloffenes Programm, das auf deiner eigenen Hardware läuft. Eigene Musik bringt die App nicht mit. Die Einrichtung mit Docker dauert wenige Minuten: Anleitung.

Häufige Fragen

Die App fragt nach einer Serveradresse. Gib die Adresse deines Servers ein, zum Beispiel https://music.example.com oder zu Hause 192.168.1.5:8000. Die App verbindet sich nur mit Servern, die sich als NxtSound melden.

Der Server ist nicht erreichbar. Prüfe, ob der Server läuft und die Adresse im Browser des iPhones funktioniert. Für einen Server im Heimnetz erlaube den Zugriff auf das lokale Netzwerk, wenn iOS fragt. Titel, die du für offline gespeichert hast, spielen auch ohne Verbindung.

Offline-Titel. Öffne das Profilmenü, dann App-Einstellungen, und schalte den Offline-Bereich ein. Du legst fest, wie viele zuletzt und am meisten gespielte Titel behalten werden, und kannst einzelne Titel auswählen.

Die Musik stoppt im Hintergrund. Die App spielt mit einem nativen Player und läuft bei gesperrtem Bildschirm weiter. Falls sie stoppt, melde es bitte mit deiner iOS-Version und was passiert ist.

Alles entfernen. App-Einstellungen → Abmelden und Server entfernen löscht die Anmeldung und alle gespeicherten Titel auf dem Gerät.
